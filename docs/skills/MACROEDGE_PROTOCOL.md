# MacroEdge Operational Protocol (v1.0)

This document contains the core identity and technical standards for the @macroedge_in brand. These rules are mandatory for all content research, design, and coding tasks.

## 1. Core Mission
MacroEdge provides high-fidelity, data-driven geopolitical and macroeconomic intelligence to investors. We bridge the gap between academic research and social media consumption.

## 2. Design Intelligence
We follow the **[frontend-design](file:///C:/Users/hp/Desktop/python/fin-guy-carousels/skills/frontend-design.md)** skill guidelines to avoid "AI Slop."

*   **Aesthetic Direction**: "Carbon & Gold" (Premium, Technical, Authoritative).
*   **Typography**:
    *   Display: **Outfit** (Bold/Black) for headings.
    *   Body: **Inter** or **Roboto Mono** for technical data.
*   **Visual Elements**:
    *   Mandatory use of ASCII for charts, flow diagrams, and market share models.
    *   Backgrounds must use mesh gradients or grain overlays to provide depth.
    *   **Zero Policy** on overused generic AI gradients (Purple/Blue/Pink).

## 3. Editorial Standards
*   **Voice**: "Head of Global Research." Cold, analytical, and objective.
*   **Content Pillars**:
    *   *Mon/Wed*: Geopolitical Chokepoints (Hormuz, Taiwan, Suez, BRICS).
    *   *Fri*: Foundational Book Summaries (Bogle, Marks, Dalio).
*   **Evergreen Rule**: Avoid specific daily prices or "today's" yields. Focus on systemic shifts and structural risks.

## 4. Technical Engine
*   **The Studio**: Built in React + Tailwind (custom theme).
*   **Export Protocol**: Use **Firefox** for high-resolution 4:5 image exports.
*   **Naming Convention**: All assets must follow `macroedge_[topic]_[slide_num].png`.
